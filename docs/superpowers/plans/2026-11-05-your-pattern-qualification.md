# Your Pattern Qualification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the completed Your Pattern PR reviewable with reproducible numerical, editorial and hosted evidence, retaining every activation boundary.

**Architecture:** Exercise the actual pinned calculation and place-search modules with synthetic fixtures. Keep reference software and hosted qualification resources separate from application dependencies and existing customer resources. Record measured evidence and unresolved release gates without turning sampled agreement into a universal proof.

**Tech Stack:** TypeScript/tsx, Astronomy Engine 2.1.19, moment-timezone 0.6.6, research-only Swiss Ephemeris 2.10.03, JPL Horizons, Cloudflare Workers/D1, existing verification tooling.

**Spec:** `docs/superpowers/specs/2026-11-05-your-pattern-design.md`; qualification scope in `docs/YOUR_PATTERN_RESULTS.md` and `docs/architecture/ASTROLOGY_UNCERTAINTY.md`.

## Global Constraints

- Preserve the 0.05° minimum guard, 2,048-instant budget and the pinned calculation identity unless a reproduced defect requires a new identity.
- Moon and Pluto remain suppressed for uncertain times. No houses, angles, aspects or transits are introduced.
- Never enable hosted Pattern through the synthetic-local content path.
- Human approval must bind the exact catalogue hash. Agent review does not constitute `human_approved`.
- Use only synthetic personal data and new qualification resources. Do not alter `reflection-preview`, its D1/R2 data or provider credentials.
- A same-account rehearsal is not acceptance of the existing hosted framework's distinct-account isolation requirement.

## Review Focus

- Sign boundaries and retrograde turns must suppress unqualified signs even when interval endpoints agree.
- Date/coordinate/time-scale conventions must be explicit for every independent ephemeris comparison.
- Cold gazetteer loading and concurrent calculations must not exceed the hosted isolate budget.
- Populated migrations and restoration must preserve saved originals and leave new publication disabled.
- Catalogue review and release wording must distinguish automated evidence from human approval and production acceptance.
