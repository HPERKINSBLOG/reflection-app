[Import service cases](../tests/db/imports.test.ts) · [Follow-up limits](../tests/db/follow-up.test.ts)

The Linux verification gate selects two file workers when four or more CPUs are available and retains the nine-minute limit. Live continuity dispatch remains disabled pending a separately authorized provider evaluation. [Synthetic evaluation receipt](../artifacts/continuity-evaluation.json)
