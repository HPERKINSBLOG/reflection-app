# Astrology data and dependency notices

Birthplace data: [GeoNames](https://www.geonames.org/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Extracted and normalized from cities15000 and administrative labels. Data is supplied as is. Source and artifact hashes are recorded in content/astrology/places-manifest.json.

IANA time zone data is in the public domain; packaged with the pinned moment-timezone data release.
